Ranked by contribution to the variance of the total, not by how much each line costs. A cheap material that moves unpredictably outranks an expensive one that doesn't.

    The model

    Measured on held-out projects

    Two gradient-boosted models: a regressor for waste per line, a classifier for overrun per project. Split by project, so no project appears on both sides of the line.

    The band is calibrated, not decorative

    The contingency is the distance from the budget to the 90th percentile of the simulated cost — which is why it moves when the distribution's shape moves, not just its centre.

    Run it

    The live tool needs a Python process

    This page is static. The predictor itself is a Flask app that loads the trained model and runs the simulation per request — so it runs locally, or on any host that executes Python. 

    # clone and run — first launch fits the models, about 50 seconds
git clone https://github.com/AkurasKurasa/mcwp.git
cd mcwp
python -m pip install -r requirements.txt
python app.py
# http://127.0.0.1:5000

    Why the predictor isn't running on this page

    GitHub Pages serves files; it does not run processes. There is no Python here to load the model or run the Monte Carlo, so the numbers above are a saved run rather than a live one.

    The repository ships a render.yaml and a Procfile. Point a Python host at either and the tool works exactly as it does locally.
